# مقایسهٔ نسخه‌های تقویم

> پیاده‌سازی: `scripts/revision_diff.py` · مصرف: `ingest_pdf.py` و
> `review_changes.py` · آزمون: `tests/test_event_history.py::DiffTest`

## ۱. محدوده

مقایسه فقط بین دو نسخه از **همان سال** انجام می‌شود. اگر سالِ ردیف‌ها یا
`year`/`new_year` یکی نباشد، `ValueError` می‌دهد. بررسیِ چندساله فقط با
درخواستِ صریح و جداگانه مجاز است و در این ابزار پیاده نشده.

## ۲. دسته‌ها

| دسته | معنا | پیش‌فرض |
|---|---|---|
| `UNCHANGED` | همان عنوان و همان تاریخ | خودکار، بدونِ تصمیم |
| `UNCHANGED` + `variantOnly` | فقط تفاوتِ نگارشی/OCR (فاصله، نیم‌فاصله، `ه‍.ش`/`هو ش`، `(تعطیل)`) | خودکار، عنوانِ قدیم حفظ می‌شود |
| `RENAMED` | عنوان در همان تاریخ عوض شده | نیازمندِ تصمیم |
| `DATE_CHANGED` | همان عنوان، تاریخِ دیگر | نیازمندِ تصمیم |
| `MODIFIED` | تعطیلی/قمری/میلادی یا عنوان+تاریخ با هم | نیازمندِ تصمیم |
| `ADDED` | در نسخهٔ جدید هست، در قبلی نبود | نیازمندِ تصمیم |
| `REMOVED` | در نسخهٔ قبلی بود، در جدید نیست | نیازمندِ تصمیم |

`requiresHuman = kind != UNCHANGED`؛ `autoAcceptable = kind == UNCHANGED`.

## ۳. ترتیبِ تطبیق

1. **کلیدِ کانونیِ یکسان** (بدونِ شماره/سال/افتخار): جفت می‌شوند؛ اگر تاریخ
   یکی باشد `UNCHANGED`/`MODIFIED`، وگرنه `DATE_CHANGED`.
2. **همان تاریخ + شباهتِ عنوان ≥ ۰٫۷۲**: `RENAMED`.
3. **جفتِ باقی‌مانده با شباهت ≥ ۰٫۸۰** (حتی با تاریخِ متفاوت): `MODIFIED`
   (عنوان+تاریخ).
4. **بی‌جفت‌ها**: `REMOVED` و `ADDED`.

تفکیکِ «تغییرِ واقعی» از «تفاوتِ نگارشی»:

- شباهت ≥ ۰٫۹۲ → `UNCHANGED variantOnly`؛
- یا شباهت ≥ ۰٫۸۵ و فاصلهٔ لِوِنشتاین ≤ ۲ → `UNCHANGED variantOnly`؛
- `compare_key` پیش از سنجش، `ه‍.ش`/`هو ش`/`ه.ق`/`تعطیل`/پرانتز/نویسه‌های
  دوسویه را یکسان می‌کند؛ ارقام را برای تشخیصِ تغییرِ سال حفظ می‌کند.

## ۴. تکراری‌ها و ردیفِ شکسته

- **تکراری**: دو ردیفِ هم‌زمان با کلیدِ کانونیِ یکسان در نسخهٔ جدید →
  `diff.duplicates` و `duplicateGroup` روی تغییرها.
- **شکسته**: ردیفِ `ADDED` که قطعه‌ای از یک `REMOVED` است (زیررشته با پوشش
  ≥۲۰٪) یا پرچمِ `fragment` دارد → `suspectedSplit` / `suspectedFragment`.
  این‌ها تصمیمِ انسانی می‌خواهند و هرگز خودکار اعمال نمی‌شوند.

## ۶. آنچه مقایسه **نمی‌کند**

- تغییرِ هویت را خودکار اعمال نمی‌کند؛ فقط پیشنهاد می‌دهد.
- تفاوتِ تاریخِ قمری/میلادی را به‌تنهایی «تغییرِ رویداد» نمی‌داند؛ `MODIFIED`
  با فیلدهای صریح گزارش می‌شود تا بازبین ببیند.
- حذفِ یک ردیف را «نبودِ واقعیِ رویداد» تفسیر نمی‌کند؛ فقط «در این نسخه دیده نشد».
